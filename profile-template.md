# Developer profile (template)

Copy this file to Google Drive (or adapt it) and point your workflow at it. The scoring step compares each Upwork posting against these fields.

## Identity

- **Name / headline:** (how you present on Upwork)
- **Primary role:** (e.g. backend, full-stack, data)

## Skills and stack

- **Must-have technologies:** (languages, frameworks, infra you want to work in)
- **Nice-to-have:** (bonus points if mentioned)
- **Hard exclusions:** (tech or domains you will not take)

## Engagement

- **Rate expectations:** (hourly range or fixed-budget rules)
- **Timezone / overlap:** (hours or regions you can align with)
- **Contract types:** (hourly only, long-term, short gigs, etc.)

## Job preferences

- **Industries or product types:** (what you like)
- **Avoid:** (spam sectors, vague RFPs, unpaid trials, etc.)

## Scoring hints for the model

Optional bullets the Haiku step can use as explicit rules (e.g. “penalize if budget not stated”, “boost if stack matches X”).
